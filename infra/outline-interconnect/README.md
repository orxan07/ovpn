# Восстановление маршрута SSTP через Outline

В панели откройте **Прокси → Маршрут SSTP через Outline → Восстановить маршрут**.
Операция восстанавливает интерфейс основной VPS, применяет внутренний адрес к активному профилю этого сервера, запускает sing-box и выполняет HTTPS-запрос с адреса шлюза SSTP и маркой 0x2023. Успех требует ответа с внешним IP 156.67.63.163. Для проверки нужен доступный адрес шлюза 10.27.0.1 и работающий DNS. Применение изменившегося профиля перезапускает sing-box.

## Установка

Скопируйте этот каталог на обе VPS. На основной выполните от root `bash install.sh gateway`, на выходной — `bash install.sh exit`. На выходной VPS должен работать Outline на TCP/UDP 25235. Для основной VPS нужен сохранённый активный профиль этого Outline. Установщик привязан к адресам развёртывания и проверяет локальный адрес.

Обе VPS независимо проверяют интерфейс olpath0 каждые 30 секунд. Это позволяет выходной VPS восстановить свою сторону даже при потере межсерверной связи. Туннель IP-in-IP разрешает доступ к Outline поверх существующего шифрования Shadowsocks. Правила nftables запрещают транзит с интерфейса. При проблеме проверьте `systemctl status outline-interconnect-ensure.timer` и `journalctl -u outline-interconnect-ensure.service` на обеих сторонах. Ошибка конечной проверки также возможна при отказе DNS, HTTPS-сайта проверки или связи между провайдерами.
