# Индивидуальные маршруты SSTP

В панели: **SSTP → Маршруты**.

1. Во вкладке «Клиенты» создать отдельного пользователя для каждого устройства.
2. Создать профиль, например «Дети», выбрать группу ChatGPT и нужных клиентов.
3. Нажать «Применить изменения». На Android использовать обычный Open SSTP
   Client с сервером `171.22.75.104`, портом `14942` и реквизитами своего клиента.

Группа — редактируемый набор доменов и их поддоменов. Профиль объединяет
несколько групп. Выбранные домены идут через Outline; остальные назначения
идут через основную VPS, даже если входят в общий whitelist или глобальный
режим «Всё через Outline». Пользователи без профиля сохраняют общие правила.
Пустой набор групп означает прямой выход через основную VPS.

Это серверная маршрутизация, а не split tunneling на телефоне: весь SSTP-трафик
сначала доходит до VPS. Это также не запрет других сайтов. Общие сервисные
домены в группе, например WorkOS или Cloudflare Challenges, могут обслуживать
несколько сайтов. Группа ChatGPT содержит его веб-домены и зависимости входа,
статики, файлов и служебных функций; при изменении зависимостей её можно
обновить целиком. Источник списка: официальные сетевые рекомендации OpenAI:
https://help.openai.com/en/articles/9247338-network-recommendations-for-chatgpt-errors-on-web-and-apps

## Применение

Панель валидирует весь набор до изменений и проверяет конфигурацию установленным
`sing-box check`. Для назначенных клиентов резервируются постоянные адреса
`10.27.0.160–239`, вне поддерживаемого динамического пула `10.27.0.2–100`.
При первом назначении включается `gw-ip-address=10.27.0.1` в `[chap-secrets]`.
Согласно установленному accel-ppp, записи `*` продолжают получать IP из пула.

Правила source IP + домен ставятся после sniff/DNS hijack, но перед общими
маршрутами. Последнее правило профиля — direct. DNS-кеш разделяется по DNS
серверам (`independent_cache` в sing-box 1.13), иначе кеш одного профиля может
подменить выбор DNS другого. Удаление последнего назначения возвращает прежнюю
настройку кеша. Требуется повторная проверка совместимости перед обновлением
sing-box на версии, где `independent_cache` удалён.

Изменения активных маршрутов кратко перезапускают sing-box. Смена или снятие
постоянного адреса отключает сессии только затронутых пользователей; им нужно
переподключиться. Редактирование неиспользуемой группы не перезапускает VPN.
Steam UDP сохраняет ранее настроенный прямой обход TUN.

Метаданные: `data/sstp-routing.json`, права `600`. Незавершённая операция имеет
журнал `data/sstp-routing.json.pending`, также `600`; в нём есть защищённая
резервная копия конфигурации и chap-secrets. При ошибке предыдущие файлы
восстанавливаются; после сбоя процесса восстановление выполняется при старте
панели. Если оно не удалось, API маршрутов возвращает ошибку, а журнал
сохраняется для восстановления. Не публиковать и не выводить журнал.

Редактор общих доменов не меняет профильные правила. Если профильные правила
или назначенные адреса изменены вручную, сохранение прекращается с ошибкой.
Одновременное редактирование защищено номером версии; при конфликте нужно
загрузить актуальные настройки.

Публичные API требуют существующую авторизацию панели:
`GET /api/sstp/routing`, `PUT /api/sstp/routing`.
Новые таблицы или миграции БД не используются.
